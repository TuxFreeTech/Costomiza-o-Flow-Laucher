# Configuração do Flow Launcher

## 1. Requisitos

- Windows
- Flow Launcher 2.1.3
- Tema Flow Tahoe

## 2. Instalação do Flow Launcher

Instale o Flow Launcher normalmente no Windows.

Após a instalação, abra o aplicativo e acesse:

**Configurações → Aparência**

## 3. Instalação do Flow Tahoe

O projeto utiliza o tema **Flow Tahoe**, desenvolvido por LucasM314.

O arquivo `Flow Tahoe.xaml` deve ser colocado na pasta de temas do
Flow Launcher.

A maneira mais simples de localizar a pasta correta é utilizar a opção
**Abrir pasta de temas** disponível nas configurações de Aparência.

Após copiar o arquivo:

1. Feche completamente o Flow Launcher.
2. Abra o Flow Launcher novamente.
3. Acesse **Configurações → Aparência**.
4. Selecione **Flow Tahoe**.

## 4. Configuração do tema

Com o Flow Tahoe selecionado, foram utilizados os seguintes ajustes:

| Opção | Valor |
|---|---|
| Fixed Window Size | Ativado |
| Maximum Results | 7 |
| Show Placeholder | Desativado |

Essas configurações mantêm a janela compacta e limitam a quantidade de
resultados exibidos.

## 5. Personalização

Não foram realizadas alterações no arquivo `Flow Tahoe.xaml`.

A personalização foi feita utilizando as opções disponíveis na interface
do Flow Launcher.

A intenção foi preservar o design original do tema e alterar somente o
necessário para adequá-lo ao uso diário.

## 6. Resultado

O resultado é uma interface compacta, escura e organizada, inspirada no
Spotlight do macOS Tahoe.

![Flow Launcher com Flow Tahoe](../images/flow-tahoe-search.png)

## 7. Observações

A configuração foi testada no Flow Launcher 2.1.3.

O tema foi instalado manualmente e reconhecido normalmente pelo aplicativo.

Para manter a configuração simples e fácil de reproduzir, não foram
utilizados scripts ou modificações adicionais no tema.
